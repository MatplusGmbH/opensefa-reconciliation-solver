Nonlinear solver interface module

OpenSEFA.NonlinearSolveInterfaceModule — Module

Interface between data reconciliation problems and NonlinearSolve.jl: a Julia package for high-performance and differentiation-enabled nonlinear solvers (Newton methods), bracketed rootfinding (bisection, Falsi), with sparsity and Newton-Krylov support.

source
OpenSEFA.NonlinearSolveInterfaceModule.NonlinearSolver — Type

Solve the problem using any solver available from the NonlinearSolve.jl Julia library.

OpenSEFA.NonlinearSolveInterfaceModule.nlls! — Method
