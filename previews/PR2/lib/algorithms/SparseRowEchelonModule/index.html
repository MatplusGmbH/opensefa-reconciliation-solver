Sparse row echelon module

OpenSEFA.SparseRowEchelonModule — Module

Reduced row echelon form computation optimized for sparse matrices.

This module extends the functionality of RowEchelonModule by adding specialized methods for sparse matrices that avoid conversion to dense format.

Compute a basis for the nullspace of a sparse matrix using the sparse RREF implementation.

Parameters:

  • A: Input sparse matrix
  • ɛ: Tolerance for determining zero pivots

Returns:
